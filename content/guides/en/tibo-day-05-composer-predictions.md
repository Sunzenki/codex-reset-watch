The [Day 5 announcement](https://x.com/thsottiaux/status/2108645667451318747) adds **composer predictions** to Codex desktop: suggestions for the next message based on the conversation and the user’s writing. Tibo says the prediction itself consumes no usage. The quoted @OpenAIDevs announcement identifies a beta for Pro users.

## Where suggestions can reduce repeated typing

When refining the same task, users often add similar instructions. A suggested next message can save typing, provided its wording and scope match the current intent. The announcement describes message suggestions, rather than automatically sending or executing them.

A reader asks whether Plus is included. The announcement reviewed for that day establishes the Pro beta; it does not specify Plus availability.

## Create a dot directly on mobile

In a [same-day addition](https://x.com/thsottiaux/status/2108646052178092403), Tibo quotes ChatGPT’s announcement that users can create a dot and message it directly on iOS and Android. This brings the creation step to mobile instead of first requiring desktop or web access.

The mobile change and composer predictions address different actions: creating a dot and composing a follow-up message.
