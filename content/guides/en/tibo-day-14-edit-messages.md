[Day 14](https://x.com/thsottiaux/status/2111990254408434095) adds the ability to edit previously sent messages in the same desktop thread. It offers a direct correction path when an earlier prompt used the wrong condition and the user wants to work from revised instructions.

## How is this different from steering?

James Stewart [asks](https://x.com/JamesStewau0y5/status/2111991077490360408) whether editing an earlier prompt behaves like steering. Tibo [replies](https://x.com/thsottiaux/status/2111994295364571327) that it registers as “time travel.”

The reply separates two interactions: steering supplies direction during execution, while editing an old message returns to an earlier position. For an extra constraint on a running task, compare [Day 4’s instant steering change](/guides/tibo-day-04-steering-ultrafast/).

## What happens to existing work?

This exchange does not fully specify branching, retention of later messages or rollback of files and external actions. Returning through conversation history alone does not establish that files, commits or external actions will be undone automatically.

Read the current client’s prompts before using the feature, then inspect existing results afterward. This review covers the public messages and exchange; CRW did not run a file-restoration test.
