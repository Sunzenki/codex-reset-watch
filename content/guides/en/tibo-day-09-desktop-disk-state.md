The [Day 9 update](https://x.com/thsottiaux/status/2110151780478927344) changes how the ChatGPT and Codex desktop apps store state data. Tibo expects roughly 60% less disk space for this data, addressing reports from heavy users running short of space.

## Which disk usage may decrease?

The announcement concerns state accumulated by the application. It does not put installation packages, project files or all other system caches under the same percentage. Applying 60% to the entire disk or application directory would overstate its scope.

This is particularly relevant to desktop users with many conversations and long-running tasks. To observe a change, compare application-state storage under similar activity. CRW has not measured disk usage before and after the update.

## Is manual cleanup required?

The post provides no migration or cleanup procedure and does not ask users to delete configuration. There is no need to follow third-party cleanup suggestions in replies and remove local conversations or work directories merely to obtain this optimization.
