Day 2 的[四项更新](https://x.com/thsottiaux/status/2107575657014468879)分别面向 Codex 长任务、API 开发者和会议协作用户。最直接影响日常用量的是 Auto-review 免费；当天稍后还有一次重置确认。

## 在哪里开启免费的 Auto-review

[Day 2.1 公告](https://x.com/thsottiaux/status/2107368734981517634)说明，通过 ChatGPT 账号登录的用户，Auto-review 不再消耗套餐用量。它由另一个代理审查主代理的动作，识别高风险或偏离用户意图的操作，减少长任务中逐次审批的负担。

Tibo 在[回复](https://x.com/thsottiaux/status/2107504197012988007)中补充了入口：打开输入框下方的权限菜单，选择 **Approve for me**。主帖还给出 Settings → Permissions → Auto-review 路径。不同版本的命名可能变化，可对照[官方 Codex 套餐说明](https://help.openai.com/en/articles/11369540-using-codex-with-your-chatgpt-plan)。

Tibo 在当天汇总中提到，自动审查原本可能占套餐用量的 2%–10%。这是作者对原审查开销的说明，实际节省取决于任务；主任务照常消耗用量，工作区已有权限限制继续生效。

## API 最高层级的门槛降低

[Day 2.2 引用的 @OpenAIDevs 公告](https://x.com/thsottiaux/status/2107548725359104441)将五档付费 API 使用层级简化为 **Build、Launch、Grow**。进入最高 Grow 层级的累计 API 付款门槛，从原最高档的 1,000 美元降到 500 美元。

对 API 开发者，这关系到获得更高速率限制的资格。它调整的是使用层级门槛，没有在这条公告中改变模型单价或 ChatGPT 订阅额度。

## Meetings 和 Decisions API 的使用条件

[ChatGPT 的 Meetings 公告](https://x.com/ChatGPT/status/2107567930557026653)明确了当时的范围：**macOS 桌面端、Pro 与 Business 用户、测试版**；Enterprise 尚待推出。在插件目录搜索 Meetings，即可查找这一入口。

插件将个性化会议摘要和下一步事项保存到 ChatGPT Space，可保持私密或分享给团队，再用这些背景继续拟项目计划或跟进内容。

[Decisions API](https://x.com/thsottiaux/status/2107574912349303197)则面向开发者公测，用于快速选择模型、工具或下一步动作。官方“最高快 10 倍”的比较对象是通过 Responses API 调用 GPT-6 Luna 的决策过程，属于特定场景的速度宣称。
