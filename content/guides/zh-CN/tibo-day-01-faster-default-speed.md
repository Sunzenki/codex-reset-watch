[Tibo 在 Day 1](https://x.com/thsottiaux/status/2107158998495748264)宣布，GPT-6 Astra 与 GPT-6.1 Sol 通过订阅使用时，默认生成速度提升约 50%。这项调整在服务端推出，用户无需更改设置；作者当时预计两小时内可以感受到变化。

## 哪些入口包含在内

范围包括 OpenAI 自有产品，以及使用 **Sign in with ChatGPT** 的合作工具，原帖举例有 OpenCode、Pi、Amp 和 Devin。关键是使用 ChatGPT 订阅身份登录；通过 API key 单独付费的请求，需要看 API 自身的说明。

## 输出更快，任务能快多少

Tibo 在[补充回复](https://x.com/thsottiaux/status/2107159119107146237)中以约 30 TPS 到 50 TPS 说明生成吞吐变化。TPS 指每秒生成的 token 数，适合观察回答输出的速度；完整编码任务还要经过思考、工具调用、文件处理和网络等待。

因此，长任务总耗时不一定按相同比例下降。对比效果时，使用相同模型、相近任务和同一登录方式更有参考价值。约 50% 是作者公布的优化幅度，本次调整也没有宣布增加套餐额度。
