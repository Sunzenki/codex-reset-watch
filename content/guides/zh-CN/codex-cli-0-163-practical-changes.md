[Codex CLI 0.163.0](https://github.com/openai/codex/releases/tag/rust-v0.163.0)于 2026 年 10 月 15 日发布。对经常在终端里使用 Codex 的用户，值得关注的是设置查找、任务中途补充要求，以及恢复旧会话和 Windows 粘贴时的修复。

## 用 /config 找设置，留意是否需要重启

交互会话中的 `/config` 可以跨分类搜索偏好设置，支持的选项可立即修改，并区分哪些变化需要重启。找不到一个开关时，可以先在这里确认当前选项，而不是直接猜配置文件里的键名。

更新前先用 `codex --version` 看自己运行的 CLI 版本。桌面应用的版本号和终端里的 CLI 安装分别核对；这篇发布说明不能直接证明桌面应用已经包含同样的改动。

## 执行中追加要求，打断行为更完整

该版本支持在 Codex 回答时发送后续消息，立即调整任务方向。比如发现修改范围过大，可以补充“先只处理登录模块”。发布说明还明确，打断当前轮次会停止活动中的 Code Mode 单元及其嵌套工具调用。

对于已落盘的修改，仍应查看差异后再决定下一步。更快接收纠正有助于减少继续偏离，但一次打断并不替代对已有成果的检查。

## 恢复会话、Windows 与 WSL 的变化

| 场景 | 0.163.0 说明 |
| --- | --- |
| 恢复保存的会话 | 恢复其权限和网络批准，同时遵守明确覆盖项及当前托管策略 |
| Windows 粘贴 | `Ctrl+V`、`Shift+Insert` 同时支持文本和图片 |
| WSL 反复粘贴或复制 | 复用剪贴板读取器，复制尝试以超时结束，避免挂起 |
| 子进程保持输出管道打开 | 改善本地命令的结束行为；远程命令保留晚到输出供最后一次轮询收取 |

如果你正好遇到其中一种症状，升级后应在原来的终端、项目和操作方式下复现，确认对应问题是否消失。本文整理的是发行说明，没有在本站环境逐项实测这些修复。

## 升级前后保留哪些信息

记录 CLI 版本、操作系统、启动方式和最短复现步骤；更新后重复同一步骤。若问题只在恢复旧会话时出现，把“新会话正常、恢复会话异常”一并写入反馈，会比只说“Codex 卡住了”更容易定位。
