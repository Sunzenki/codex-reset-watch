[Tibo 的 Day 25 原帖](https://x.com/thsottiaux/status/2115850175868727621)宣布 Pro 100、Pro 200、Pro 500 和 Business Premium 的额度调整当天生效。[OpenAI 更新后的 Pro 说明](https://help.openai.com/en/articles/9793128-about-chatgpt-pro-tiers)进一步明确：对于 Work 和 Codex，**Pro 100、Pro 500 的原有额度翻倍；Pro 200 则要看账号此前处于哪一档额度**。

## 各套餐实际怎么变

| 套餐或席位 | Work 和 Codex 额度变化 |
| --- | --- |
| Pro 100、Pro 500 | 官方说明，套餐原有包含额度翻倍。 |
| Pro 200，原本是较高额度 | 原定降额取消，保持现有高额度。 |
| Pro 200，原本是较低额度 | 原有低额度翻倍，提升到与高额度一致；新订阅也采用统一后的额度。 |
| Business Premium | Tibo 宣布额度翻倍；原帖未逐一列出各产品的具体窗口。 |
| Plus | OpenAI 的 Pro 帮助页面表示，Plus 用量不变。 |

OpenAI 说明，现有用户的 Work 和 Codex 额度自动调整，不需要等待续费。所有 Pro 200 订阅现在使用相同额度，月费仍为 200 美元。**已经享有较高额度的 Pro 200 用户，是保留原额度，不是在原高额度上再翻倍。**

## 为什么 Pro 200 要单独解释

Tibo [此前说明](https://x.com/thsottiaux/status/2104823812042940713)，新的 Pro 200 额度计算按 API 美元支出衡量大约是旧方案的一半；帮助中心后来公布了符合条件的老订阅过渡期。OpenAI 现在表示，9 月 29 日邮件中宣布的降额已取消。本站[此前的 Pro 200 文章](/zh-CN/guides/pro-200-grandfathered-allowance-october-2026/)已据此更正。

更新后的官方说明还区分 **Chat** 与 Work、Codex：Pro 100 和 Pro 500 的 Chat 中 GPT-6 Pro 每周消息限制维持原状；Pro 200 的低档 Chat 限制提高到与高档一致。套餐额度提高并不保证完成的任务数量恰好翻倍，实际消耗仍取决于模型、上下文和设置。

## dot 额度怎样计算

Tibo 表示 dot 的扩展额度暂时继续，dot 用量仍与默认用量分开，但没有给出新的结束日期。[dot 官方文档](https://learn.chatgpt.com/docs/dots)区分了与 dot 的对话，以及 dot 在 Work 或 Codex 中发起或管理的任务：后者仍计入对应产品的用量限制。不能理解为 dot 发起的所有任务都不消耗套餐额度。

请在自己的[用量面板](https://chatgpt.com/codex/settings/usage)核对账号和工作区。这次是套餐额度规则调整，并非预告一次性重置；也不改变独立的[订阅 API 赠额](/zh-CN/guides/chatgpt-pro-business-api-credits/)规则。
