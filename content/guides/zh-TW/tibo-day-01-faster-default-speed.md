[Tibo 在 Day 1](https://x.com/thsottiaux/status/2107158998495748264)宣佈，GPT-6 Astra 與 GPT-6.1 Sol 透過訂閱使用時，預設生成速度提升約 50%。這項調整在服務端推出，使用者無需更改設定；作者當時預計兩小時內可以感受到變化。

## 哪些入口包含在內

範圍包括 OpenAI 自有產品，以及使用 **Sign in with ChatGPT** 的合作工具，原貼文舉例有 OpenCode、Pi、Amp 和 Devin。關鍵是使用 ChatGPT 訂閱身份登入；透過 API key 單獨付費的請求，需要看 API 自身的說明。

## 輸出更快，任務能快多少

Tibo 在[補充回覆](https://x.com/thsottiaux/status/2107159119107146237)中以約 30 TPS 到 50 TPS 說明生成吞吐變化。TPS 指每秒生成的 token 數，適合觀察回答輸出的速度；完整編碼任務還要經過思考、工具呼叫、檔案處理和網路等待。

因此，長任務總耗時不一定按相同比例下降。對比效果時，使用相同模型、相近任務和同一登入方式更有參考價值。約 50% 是作者公佈的最佳化幅度，本次調整也沒有宣佈增加方案配額。
