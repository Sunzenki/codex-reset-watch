[Tibo 的 Day 25 原帖](https://x.com/thsottiaux/status/2115850175868727621)宣布 Pro 100、Pro 200、Pro 500 和 Business Premium 的額度調整當天生效。[OpenAI 更新後的 Pro 說明](https://help.openai.com/en/articles/9793128-about-chatgpt-pro-tiers)進一步明確：對於 Work 和 Codex，**Pro 100、Pro 500 的原有額度翻倍；Pro 200 則要看帳戶先前處於哪一檔額度**。

## 各方案實際怎麼變

| 方案或席位 | Work 和 Codex 額度變化 |
| --- | --- |
| Pro 100、Pro 500 | 官方說明，方案原有內含額度翻倍。 |
| Pro 200，原本是較高額度 | 原定降額取消，維持現有高額度。 |
| Pro 200，原本是較低額度 | 原有低額度翻倍，提高到與高額度一致；新訂閱也採用統一後的額度。 |
| Business Premium | Tibo 宣布額度翻倍；原帖未逐一列出各產品的具體視窗。 |
| Plus | OpenAI 的 Pro 說明頁面表示，Plus 用量不變。 |

OpenAI 說明，現有使用者的 Work 和 Codex 額度自動調整，不需要等待續費。所有 Pro 200 訂閱現在使用相同額度，月費仍為 200 美元。**已經享有較高額度的 Pro 200 使用者，是保留原額度，不是在原高額度上再次翻倍。**

## 為什麼 Pro 200 要單獨說明

Tibo [先前說明](https://x.com/thsottiaux/status/2104823812042940713)，新的 Pro 200 額度計算按 API 美元支出衡量約為舊方案的一半；說明中心後來公布了符合條件的舊訂閱過渡期。OpenAI 現在表示，9 月 29 日電子郵件中宣布的降額已取消。本站[先前的 Pro 200 文章](/zh-TW/guides/pro-200-grandfathered-allowance-october-2026/)已據此更正。

更新後的官方說明還區分 **Chat** 與 Work、Codex：Pro 100 和 Pro 500 的 Chat 中 GPT-6 Pro 每週訊息限制維持原狀；Pro 200 的低額度 Chat 限制提高到與高額度一致。方案額度提高不保證完成的任務數量恰好翻倍，實際消耗仍取決於模型、上下文和設定。

## dot 額度如何計算

Tibo 表示 dot 的擴展額度暫時繼續，dot 用量仍與預設用量分開，但沒有給出新的結束日期。[dot 官方文件](https://learn.chatgpt.com/docs/dots)區分了與 dot 的對話，以及 dot 在 Work 或 Codex 中發起或管理的任務：後者仍計入對應產品的用量限制。不能理解為 dot 發起的所有任務都不消耗方案額度。

請在自己的[用量面板](https://chatgpt.com/codex/settings/usage)核對帳戶和工作區。這次是方案額度規則調整，並非預告一次性重置；也不改變獨立的[訂閱 API 贈額](/zh-TW/guides/chatgpt-pro-business-api-credits/)規則。
