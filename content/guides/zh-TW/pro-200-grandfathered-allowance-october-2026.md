OpenAI 已**取消 Pro 200 的 Work 和 Codex 原定降額**。[更新後的 Pro 說明](https://help.openai.com/en/articles/9793128-about-chatgpt-pro-tiers)表示，原本享有較高額度的帳戶繼續保留該額度；原本使用較低額度的帳戶會翻倍至同一水準。新舊 Pro 200 訂閱現在採用相同的 Work 和 Codex 額度，月費仍為 200 美元。

## 與先前的計畫相比，變了什麼

OpenAI 先前說明，符合條件的現有訂閱者可保留舊額度至 2026 年 10 月 29 日，之後轉為較低額度。Tibo 也在[先前原帖](https://x.com/thsottiaux/status/2104823812042940713)中解釋，新計算方式按 API 美元支出衡量約為舊方案的一半。OpenAI 現在明確取消了 9 月 29 日電子郵件中宣布的降額，取代本文原先寫的 10 月 29 日過渡安排。

已經享有較高 Work 和 Codex 額度的使用者是**保留原額度**，並非在高額度上再次翻倍；原本額度較低的使用者則提高到同一水準。OpenAI 說現有訂閱會自動獲得調整，無需等待續費，也無需取消後重新訂閱。其他方案變化見 [Day 25 原帖](https://x.com/thsottiaux/status/2115850175868727621)及本站 [Day 25 指南](/zh-TW/guides/tibo-day-25-pro-usage-allowance/)。

## 核對自己的額度

在[設定 → 用量](https://chatgpt.com/codex/settings/usage)查看實際使用的帳戶與工作區。Work 和 Codex 共享方案額度；模型、上下文、推理強度與設定會影響消耗。Chat 的 GPT-6 Pro 每週訊息限制另計：Pro 200 原低額度提高到與高額度一致，原高額度維持不變。

[訂閱 API credits](/zh-TW/guides/chatgpt-pro-business-api-credits/)是獨立權益，不會增加登入狀態下的 Codex 限制，也不能用於透過 API key 使用 Codex。重置只會重新整理適用視窗，本身不會改變方案額度。
