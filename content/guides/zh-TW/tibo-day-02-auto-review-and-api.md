Day 2 的[四項更新](https://x.com/thsottiaux/status/2107575657014468879)分別面向 Codex 長任務、API 開發者和會議協作使用者。最直接影響日常用量的是 Auto-review 免費；當天稍後還有一次重置確認。

## 在哪裡開啟免費的 Auto-review

[Day 2.1 公告](https://x.com/thsottiaux/status/2107368734981517634)說明，透過 ChatGPT 帳號登入的使用者，Auto-review 不再消耗方案用量。它由另一個代理審查主代理的動作，識別高風險或偏離使用者意圖的操作，減少長任務中逐次審批的負擔。

Tibo 在[回覆](https://x.com/thsottiaux/status/2107504197012988007)中補充了入口：開啟輸入框下方的權限選單，選擇 **Approve for me**。主貼文還給出 Settings → Permissions → Auto-review 路徑。不同版本的命名可能變化，可對照[官方 Codex 方案說明](https://help.openai.com/en/articles/11369540-using-codex-with-your-chatgpt-plan)。

Tibo 在當天彙總中提到，自動審查原本可能佔方案用量的 2%–10%。這是作者對原審查開銷的說明，實際節省取決於任務；主任務照常消耗用量，工作區已有權限限制繼續生效。

## API 最高層級的門檻降低

[Day 2.2 引用的 @OpenAIDevs 公告](https://x.com/thsottiaux/status/2107548725359104441)將五檔付費 API 使用層級簡化為 **Build、Launch、Grow**。進入最高 Grow 層級的累計 API 付款門檻，從原最高檔的 1,000 美元降到 500 美元。

對 API 開發者，這關係到獲得更高速率限制的資格。它調整的是使用層級門檻，沒有在這條公告中改變模型單價或 ChatGPT 訂閱配額。

## Meetings 和 Decisions API 的使用條件

[ChatGPT 的 Meetings 公告](https://x.com/ChatGPT/status/2107567930557026653)明確了當時的範圍：**macOS 桌面版、Pro 與 Business 使用者、測試版**；Enterprise 尚待推出。在外掛目錄搜尋 Meetings，即可查詢這一入口。

外掛將個性化會議摘要和下一步事項儲存到 ChatGPT Space，可保持私密或分享給團隊，再用這些背景繼續擬專案計畫或跟進內容。

[Decisions API](https://x.com/thsottiaux/status/2107574912349303197)則面向開發者公測，用於快速選擇模型、工具或下一步動作。官方“最高快 10 倍”的比較對象是透過 Responses API 呼叫 GPT-6 Luna 的決策過程，屬於特定場景的速度宣稱。
